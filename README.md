# Dark Gamer Portfolio

A dependency-free GitHub Pages portfolio inspired by the visual language of the Pancakes documentation site.

## Publish on GitHub Pages

1. Create a repository named `DarkGamerRoblox.github.io`.
2. Put the files from this folder in the repository root.
3. Push to the `main` branch.
4. In **Settings → Pages**, select **Deploy from a branch**, then `main` / `/ (root)` if Pages is not already enabled.
5. Your site will be available at `https://darkgamerroblox.github.io/`.

## Files

- `index.html` — portfolio content
- `styles.css` — design system and responsive layout
- `client.js` — theme, copy button, navigation state, mobile drawer
- `assets/favicon.svg` — site icon
- `.nojekyll` — disables Jekyll processing

## Before publishing

Review the visit count, project descriptions, and contact links in `index.html` so every public claim is exactly how you want it presented.
